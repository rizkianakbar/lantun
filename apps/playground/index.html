Questions

Is Lantun free?

Yes. It is open source under the MIT licence. The lifelike voices are made on each reader's device, so there is no API key, no account and no cost per listen.

Does it work with WordPress, Ghost, Webflow or Shopify?

Yes. Paste the two script lines into your theme's footer or custom code setting. Lantun finds the article on each page by itself. If it ever picks the wrong part, point it at your article with data-content-selector.

Will it slow my site down?

The widget is about 38 kB gzipped and starts after your page has loaded. The lifelike voices (about 31 MB) download only when a reader picks one, and then stay cached in their browser.

Which languages does it read?

Any language the reader's browser has a voice for. The lifelike voices speak English. The dock itself is in English or Indonesian, following the page language.

What about privacy?

Lantun has no server and collects nothing. The lifelike voices run entirely in the browser. Some browsers' own "online" voices are provided by the browser maker, as with any use of those voices.

Is the widget itself accessible?

It works fully by keyboard, speaks clearly to screen readers, respects reduced motion, and is checked with axe in every state.
