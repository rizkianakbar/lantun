Your Body Text Is Probably Too Small

May 20, 2026 by Dev Patel

Open any ten blogs and you will find body text set somewhere between 14 and 16 pixels. On a phone held at arm's length, or a laptop on a desk, that is often too small for comfortable reading. The fix is simple, and it takes about three lines of CSS.

Start from the reader's setting

Browsers ship with a default font size, usually 16px, and readers can change it. If you set html { font-size: 62.5% } to make the maths easier, you quietly throw that preference away. Use rem for type, and leave the root alone.

html { font-size: 100%; }
body { font-size: 1.125rem; line-height: 1.6; }
p, li { max-width: 68ch; }

That gives 18px body text for most people, a line height that leaves room for ascenders and descenders, and a line length that keeps the eye from getting lost on wide screens.

Test it the boring way

Zoom your page to 200% and see what breaks. Then set your browser's default font size to "very large" and do it again. WCAG asks that text can be resized up to 200% without loss of content or function, e.g. no clipped buttons, no overlapping columns.

It is also worth reading your article on an actual phone, outdoors, in daylight. You will learn more in five minutes than in an hour of tweaking values in dev tools.

What about line height?

A line height of around 1.5 is a sensible default for body copy. Headings can go tighter, around 1.2, because they are short and set larger. And never set line height in pixels: it will not scale when the reader enlarges the text.

None of this is new. But it keeps coming up, so it seemed worth writing down one more time.
